# ASTRA SOVEREIGN

## Visão Geral

Astra Sovereign é um RPG Simulator Web inspirado em Anime Astral.

O objetivo é explorar mundos, derrotar inimigos, enfrentar bosses, invocar Units através do Gacha e desbloquear novos mundos.

O jogo será desenvolvido para navegador utilizando Three.js, TypeScript e Vite.

---

## MVP (Primeira versão)

- Player
- Movimento
- Mundo 1
- Mobs
- Boss
- Auto Attack
- Gacha
- Units
- Quests
- Portal
- HUD
- Save Local
